# سیاست رسانه پاتوق v12

این محدودیت‌ها هم در UI و هم در Backend اعمال می‌شوند؛ بنابراین نسخه دستکاری‌شده کلاینت نمی‌تواند از محدودیت اصلی عبور کند.

- پست Timeline: حداکثر **۲۰ عکس/ویدئو** در هر پست.
- Story: حداکثر **۲۰ عکس/ویدئو** در هر Story.
- ویدئوی Post/Story: حداکثر **۱۲۰ ثانیه**.
- Group/Channel: برای **تعداد عکس و فایل صوتی** محدودیت محصولی تعریف نشده است.
- Group/Channel video: هر ویدئو حداکثر **۱۰ MiB**.
- Storage یک سقف فنی 100MiB برای هر Object دارد تا از abuse و هزینه نامحدود جلوگیری شود؛ این سقف فنی با محدودیت محصولی تعداد عکس/ویس تفاوت دارد.

ویدئوهای Post/Story در Edge Function از روی Movie Header فایل MP4/MOV بررسی می‌شوند. فایل ویدئویی که مدت آن قابل تشخیص نباشد Reject می‌شود.

Media bucket خصوصی است و URL مستقیم عمومی ندارد؛ لینک مشاهده کوتاه‌مدت پس از Access Check صادر می‌شود.
