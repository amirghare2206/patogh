# متن پیشنهادی فروشگاه‌ها

**نام:** پاتوق

**عنوان کامل پیشنهادی:** پاتوق؛ رویداد، دورهمی و تجربه

**توضیح کوتاه:** رویدادهای شهر، دورهمی، سفر، بازی، استوری، گروه و خاطره؛ آدم‌های واقعی و تجربه‌های تازه در پاتوق.

**توضیح بلند:**
پاتوق جایی برای پیدا کردن و ساختن تجربه‌های واقعی است. رویدادهای شهر را ببین، بر اساس علاقه و موقعیتت فیلتر کن، رزرو انجام بده، با شرکت‌کننده‌ها در ارتباط باش و بعد از رویداد خاطره‌ها و تجربه‌ها را ثبت کن.

امکانات اصلی شامل کشف و رزرو رویداد، استوری‌ها، گروه‌ها و کانال‌ها، تقویم مناسبت‌ها، دعوت‌نامه خصوصی، خاطرات رویداد، درخواست رویداد، ابزارهای میزبان و برگزارکننده و پنل مدیریت است.

**دسته پیشنهادی:** Events / Social / Lifestyle

**کلیدواژه‌ها:** رویداد، دورهمی، سفر، کافه، بازی، همایش، دوست، گروه، تجربه، رزرو

اطلاعات حقوقی و لینک پشتیبانی/حریم خصوصی باید با اطلاعات واقعی مالک محصول تکمیل شود.
