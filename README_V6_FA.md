# Patogh v6 Roles + Social

این نسخه روی v5 Full Stack ساخته شده و علاوه بر OTP، پروفایل، رزرو، پرداخت، Realtime Chat، Push-ready، Matching و داشبورد میزبان، معماری پنج نقش و شبکه اجتماعی پاتوق را اضافه می‌کند.

## اضافه‌شده در v6

- پنج نقش: شرکت‌کننده، کسب‌وکار میزبان، هماهنگ‌کننده، برگزارکننده/آژانس، ادمین
- رابط متفاوت برای هر نقش
- درخواست نقش حرفه‌ای و تأیید ادمین
- مدیریت دسته‌بندی پویا توسط ادمین
- تایم‌لاین تجربه کاربران
- استوری برگزارکننده و میزبان
- گروه و کانال برای همه
- پنل ادمین با کاربران، نقش‌های حرفه‌ای، رویدادها، مالی، تخلفات و گزارشات
- Migration دیتابیس و RLS برای امکانات جدید

## نصب یک‌باره

محتویات ZIP را روی ریشه پروژه patogh Merge کن. `lib` و `test` را Replace کن و `.github` فعلی را نگه دار.

سپس:

```bash
bash install_v6.sh
```

اگر موفق شد:

```bash
git add .
git commit -m "Upgrade Patogh to roles-social v6"
git push origin main
```

## Production

همان تنظیمات Production v5 را نگه دار و بعد از `schema.sql` این فایل را اجرا کن:

```text
backend/supabase/v6_roles_social.sql
```

برای مشاهده همه نقش‌ها در حالت Demo از مسیر پروفایل > نقش و سطح دسترسی استفاده کن.
